# Student Information Portal (DCIT26 - Laboratory Exercise 2)

A React application demonstrating client-side routing (`react-router-dom`) and reusable JSX components (`Navbar`, `StudentCard`, and `CourseCard`).

## Setup & Run Instructions

1. Extract this ZIP folder.
2. Open a terminal inside the `student-portal` folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
